# Privacy Sensor Canvas Blackout Brush & Redaction UI

## 1. Overview
Kuas sensor visual (redaction brush) berbasis HTML5 Canvas yang memungkinkan pengguna menghitamkan atau memburamkan (*pixelate/blackout*) area sensitif pada gambar, foto bukti transfer, atau tangkapan layar sebelum dipublikasikan.

## 2. Key Capabilities (Backlog)
- **Interactive Redaction Canvas**: Alat kuas kotak dan bebas untuk menandai area teks atau wajah yang ingin disensor.
- **Pixelation & Blackout Filter**: Opsi efek sensor hitam solid atau mozaik pixelate.
- **Non-Destructive Work State**: Menyimpan koordinat masking sensor secara terpisah sebelum di-commit secara permanen.

## 3. Integration Points
- Akan terhubung dengan `dual-asset-generator` dan `ImageTriageModal`.

## 4. Status: -1 (Backlog)
Fitur berada dalam backlog antrean pengembangan utilitas gambar tingkat lanjut.
