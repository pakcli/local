# Zero-Latency P2P Local Vault Mesh

## 1. Overview
Konsep protokol sinkronisasi peer-to-peer (P2P) terdesentralisasi tanpa server cloud yang menghubungkan perangkat laptop, PC desktop, dan mobile dalam satu jaringan WiFi lokal untuk menyinkronkan file vault dan biner media secara instan dengan enkripsi end-to-end.

## 2. Status: -3 (Dreaming / Moonshot)
> **STATUS IDE LIAR**:
> Visi sinkronisasi tanpa batas. Mengeliminasi ketergantungan pada Obsidian Sync atau Git remote untuk perangkat dalam 1 ruangan, menggunakan penemuan mDNS/WebRTC lokal.

## 3. Ide Eksplorasi
- Zero-configuration auto-discovery di jaringan lokal.
- Resolusi konflik multi-master berbasis CRDT (Conflict-free Replicated Data Types).
- Streaming aset video dan audio besar langsung antar drive komputer tanpa upload internet.
